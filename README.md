# Bookstore Full Stack Application

## Tech Stack
- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL

## Features
- Add Book
- View Books
- Update Book
- Delete Book
- Search by Title
- Sort by Price
- Filter by Price

## How to Run

### Backend
1. Open in Eclipse
2. Run DemoApplication.java
3. Runs on: http://localhost:8080

### Frontend
1. Open in VS Code
2. Run:
   npm install
   npm start
3. Runs on: http://localhost:3000

### Database
1. Import bookstore_db.sql in MySQL
